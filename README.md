# Riyan's Little Universe — V6

Website statis untuk GitHub Pages karya **Riyan Sumarno a.k.a Riyan Giting**.

## V6
- Quote utama hanya satu kartu per tampilan; tanpa scrollbar horizontal.
- Navigasi quote: tombol kiri/kanan, swipe layar sentuh, dan tombol panah keyboard.
- Koleksi quote lama dipertahankan dan ditambah Blogverse berdasarkan tema tulisan publik Riyan Giting.
- Mini Game Arcade memakai dropdown dan berisi 10 game.
- Kontak/jejak digital dideduplikasi per platform sehingga satu platform hanya tampil satu kali.
- Tetap murni HTML, CSS, JavaScript; cocok untuk GitHub Pages.

## Deploy
Upload `index.html`, `style.css`, dan `script.js` ke root repository, lalu aktifkan GitHub Pages.
