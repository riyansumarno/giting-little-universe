# Riyan's Little Universe

Website statis kawaii dan interaktif berisi quotes receh, nyeleneh, serius, visi, mimpi, impian, cita-cita, pencapaian, kehidupan, cinta, dan super power.

Pembuat: **Riyan Sumarno a.k.a Riyan Giting**

## Fitur
- Random quote spotlight
- Filter kategori quote
- Tombol copy quote
- Mini game "Tangkap Bintang Mimpi"
- Penyimpanan satu mimpi di browser menggunakan `localStorage`
- Animasi kawaii ringan
- Responsif untuk desktop dan ponsel
- Tanpa framework, cocok untuk GitHub Pages

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. GitHub akan memberikan URL website.
