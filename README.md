# Riyan's Little Universe — V5

Website statis untuk GitHub Pages milik **Riyan Sumarno a.k.a Riyan Giting**.

## Isi
- 70 quotes dalam berbagai kategori, termasuk KehiduPUNK, Tengil, Absurd, dan Kece.
- Quote vending machine ringkas: dropdown kategori, carousel horizontal, dan modal semua quote.
- Titip Mimpi: link berbagi tanpa login, penyimpanan pribadi di browser, dan Dinding Mimpi via GitHub Issues.
- 5 mini game: Bintang Bandel, Kamu Betah?, Jangan Ditekan, Cari Si Kucing, dan Suit Semesta.
- Navigasi responsif, tombol scroll-to-top, kontak, dan tampilan mobile-friendly.

## GitHub Pages
Unggah seluruh isi folder ini ke root repository, lalu aktifkan GitHub Pages dari branch `main` dan folder `/ (root)`.

## Dinding Mimpi
Dinding publik memakai GitHub Issues pada repository tempat website dipasang. File `.github/ISSUE_TEMPLATE/config.yml` mengaktifkan blank issue.
